# Pegasus Spatial 行为验收定义

`behavior-cases.json` 定义 Agent 行为的工具选择、询问、中文交付、Lux 模块化搭建、多视角输入、物体姿态复核、异步完成通知、资产并行生产与 Scene 单写者边界。单件请求允许直接调用目标工具或先生成参考图。照片还原案例检查从整体概念到单件参考、生成 GLB 和源码组装的顺序。坐标基对照案例固定“格式错误不用 Scene 变换补偿”的行为；多视角案例固定“重要模块使用一致视图且不与文字入口混用”的契约；异步案例固定“创建后继续工作、完成后独立提醒、不得追加第二个 ToolResult”的契约。

当前 CI 只运行 `verify-definitions.ts`，用于防止验收契约漂移；它不调用模型、网络或供应商，也不代表模型行为已经通过。发布前应在已配置真实凭证的验收环境中逐例重放，保存实际 tool trace、询问文本、付费提交次数和最终中文答复，再将 `model_behavior_results_available` 的事实状态记录在独立验收报告中。
