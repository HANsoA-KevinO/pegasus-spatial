# Upstream provenance

Pegasus Spatial started as an independent snapshot of [Sci-Pegasus](https://github.com/HANsoA-KevinO/sci-pegasus) on 2026-08-25, based on commit `ee5daeedc5489d50956d457b02c145a1b262c20f`. The snapshot excluded Git history, build output, caches, logs, and local environment files.

The durable Agent Runtime, Workspace versioning, memory, compaction, team coordination, model registry, and materials-research tooling originate from Sci-Pegasus. Pegasus Spatial adds its spatial creation workflow, generation adapters, asset lineage, and Three.js scene tools and stage.

The source snapshot contained no authoritative license file. See the current license statement in [README](README.en.md#license).
